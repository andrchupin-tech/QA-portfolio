# Чек-лист: модуль «Профиль пользователя»

**Приоритеты:** High / Medium / Low

---

## 1. Доступ к профилю

| Проверка | Приоритет |
|:---|:---|
| Отображение кнопки профиля в правом нижнем углу на всех страницах (главная, каталог, корзина, история заказов) | High |
| Клик по кнопке открывает меню с разделами: «Личные данные», «Клубная карта», «Уведомления», «Выход» | High |
| Закрытие профиля по клику вне области или по кнопке «Закрыть» | Medium |

---

## 2. Личные данные (редактирование)

| Проверка | Приоритет |
|:---|:---|
| Отображение текущих данных (ФИО, дата рождения, телефон, email) | High |
| Редактирование ФИО — валидное значение → сохранение → данные обновляются | High |
| Редактирование ФИО — невалидные символы → ошибка, сохранение не происходит | Medium |
| Редактирование ФИО — пустое поле → «Обязательное поле» | Medium |
| Редактирование даты рождения — корректная дата (18+) → сохранение | High |
| Редактирование даты рождения — дата в будущем → ошибка | Medium |
| Редактирование телефона — валидный номер → сохранение | High |
| Редактирование телефона — неполный номер → ошибка | Medium |
| Редактирование email — валидный формат → сохранение | High |
| Редактирование email — без @ или домена → ошибка | Medium |
| Редактирование email — уже существующий email → «Email уже используется» | Medium |
| Изменение пароля — старый пароль верный → новый сохраняется | High |
| Изменение пароля — старый пароль неверный → ошибка | High |
| Изменение пароля — новый пароль <6 символов → ошибка | Medium |
| Изменение пароля — подтверждение не совпадает → ошибка | Medium |
| Отмена изменений — данные не меняются | Medium |
| Успешное сохранение → уведомление «Данные обновлены» | Medium |

---

## 3. Клубная карта

| Проверка | Приоритет |
|:---|:---|
| Отображение статуса карты: «Активна» / «Неактивна» | High |
| Отображение номера карты | High |
| Отображение уровня карты: Базовый / Классический / Премиальный | High |
| Отображение даты активации или надписи «Активируется автоматически на следующий день после покупки» | High |
| Переключение между уровнями → сохранение → отображается выбранный | Medium |
| Попытка активации вручную при невыполненных условиях → ошибка | Medium |
| Попытка активации вручную при выполненных условиях → карта активна | High |
| Отображение истории операций по карте | Low |
| Копирование номера карты | Low |
| При неактивной карте действия, требующие активности, недоступны | Medium |

---

## 4. Уведомления

| Проверка | Приоритет |
|:---|:---|
| Отображение списка уведомлений (прочитанные / непрочитанные) | High |
| Непрочитанные выделены (жирный шрифт, точка, значок) | Medium |
| Клик по уведомлению → открытие деталей | Medium |
| Отметка одного уведомления как прочитанного | Medium |
| Отметка всех уведомлений как прочитанных | Medium |
| Удаление одного уведомления | Low |
| Удаление всех уведомлений → список пуст, плейсхолдер «Уведомлений нет» | Low |
| При пустом списке отображается корректное сообщение | Medium |
| Настройка уведомлений: включение/отключение типов (email, push, SMS) | Medium |
| Отключённые уведомления не приходят | High |
| Появление нового уведомления в реальном времени | Medium |
| Переход в уведомления через иконку «колокольчик» | Medium |

---

## 5. Выход из профиля

| Проверка | Приоритет |
|:---|:---|
| Кнопка «Выход» отображается в профиле | High |
| Клик по «Выход» → подтверждение «Вы уверены?» | Medium |
| Подтверждение выхода → разлогин, редирект на главную | High |
| Отмена выхода → пользователь остаётся в профиле | Medium |
| После выхода кнопка профиля заменяется на «Войти» | High |
| После выхода защищённые страницы недоступны → редирект на логин | High |
| Завершение сессии на всех вкладках/устройствах | Low |

---

## 6. Общие проверки интерфейса

| Проверка | Приоритет |
|:---|:---|
| Корректное отображение на разных разрешениях (десктоп, планшет, мобильный) | Medium |
| Скорость загрузки разделов профиля (не более 2–3 секунд) | Medium |
| Все тексты на русском языке, без опечаток | Low |
| Все иконки и кнопки кликабельны, курсор меняется на pointer | Low |
| При повторном входе данные сохраняются | Medium |
| Работа профиля при медленном интернете — отображение лоадеров | High |
