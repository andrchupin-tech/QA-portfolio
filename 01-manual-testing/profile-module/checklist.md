# Чек-лист: модуль «Профиль пользователя»

**Приоритеты:** High / Medium / Low

---

## 1. Доступ к профилю

| Проверка | Приоритет |
|:---|:---|
| Кнопка профиля видна на всех страницах | High |
| Клик открывает меню с разделами | High |
| Закрытие по клику вне области | Medium |

## 2. Личные данные

| Проверка | Приоритет |
|:---|:---|
| ФИО: валидное значение → сохранение | High |
| ФИО: невалидные символы → ошибка | Medium |
| Дата рождения: дата в будущем → ошибка | Medium |
| Телефон: неполный номер → ошибка | Medium |
| Email: без @ → ошибка | Medium |
| Email: уже существует → «Email используется» | Medium |
| Пароль: старый неверный → ошибка | High |
| Пароль: подтверждение не совпадает → ошибка | Medium |
| Отмена изменений → данные не меняются | Medium |
