# Баг-репорт: POST-запрос на Yandex Cloud Functions

**Severity:** Critical  
**Priority:** High  
**Тип:** Логический / API

---

## Окружение

- Postman v10
- Windows 11
- URL: https://functions.yandexcloud.net/d4e8qsrmeedndmefsus
- Метод: POST
- Content-Type: application/json

---

## Предусловие

Сервер доступен. В Postman настроен POST-запрос с заголовком Content-Type: application/json.

---

## Шаги воспроизведения

1. Открыть Postman.
2. Создать POST-запрос на указанный URL.
3. В теле запроса (raw JSON) отправить:

```json
{
  "birthday": "30.02.1999",
  "name": "Иван",
  "passport": "1234 567890",
  "patronymic": "Иванович",
  "phone": "89109991234",
  "surname": "Иванов"
}
```

4. Нажать Send.

---

## Фактический результат

Код ответа: **200 OK**

```json
{
  "success": true,
  "data": {
    "name": "Иван",
    "surname": "Иванович",
    "patronymic": "Иванович",
    "phone": "+70001112233",
    "passport": "1234 567890"
  }
}
```

**Что не так:**
1. `surname` содержит отчество («Иванович») — фамилия пропала.
2. `phone` изменён: `89109991234` → `+70001112233`.
3. Поле `birthday` отсутствует в ответе.
4. Дата `30.02.1999` принята как валидная.

---

## Ожидаемый результат

Код ответа: **200 OK**, поля соответствуют отправленным:

```json
{
  "success": true,
  "data": {
    "name": "Иван",
    "surname": "Иванов",
    "patronymic": "Иванович",
    "phone": "89109991234",
    "passport": "1234 567890",
    "birthday": "30.02.1999"
  }
}
```

**Или** (если дата невалидна):

Код ответа: **400 Bad Request**

```json
{ "error": "Неверный формат даты. День 30 не существует в феврале." }
```

---

## Влияние

- Неверная идентификация пользователя (фамилия = отчество).
- Нарушение ожиданий фронтенда (формат телефона).
- Невозможно подтвердить дату рождения.
- Ошибки при расчёте возраста и отчётности.
